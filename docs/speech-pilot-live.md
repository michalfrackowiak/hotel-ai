# Live routed speech pilot

The pilot went live on the ARM64 server on 18 November 2026 after the staffed maintenance window was confirmed. Nginx paused guest requests while the original Django writer stopped. An exclusive SQLite backup was verified against a disposable restore, then the candidate applied its migrations to that copy. The restore passed integrity, foreign-key, bilingual chat and fictional booking retry checks across 30 tables. The pinned rollback image also served both reception languages and admin login using a writable tmpfs copy of the migrated restore.

The routed Piper and Vosk primaries passed bound inference checks for English and Polish. The authenticated loopback controller reported all four initial routes at revision zero without pending operations. The standby and legacy workers are stopped. Django uses the original booking volume and the private traffic-store bind mount. Staff switching and recovery remain disabled.

The workstation verified bilingual Piper WAV playback and Vosk PCM handling over public HTTPS. Public `/admin/` returned 404. The Django login page returned 200 through an SSH forward, and direct TCP connections from the workstation to the Django and controller ports failed. The production check covered the login page and authenticated controller API. The earlier SSH rehearsal covered form submission with CSRF and a fixture staff account.

Two startup attempts reverted to the fixed stack before any candidate migration. The first encountered the delay between Nginx reload and the maintenance response. The second found that Django writes a session when testing the rollback image, so its temporary test database needs to be writable. The successful run waited for the expected Nginx response and gave the rollback fixture its own writable tmpfs. The live source remained read-only during backup verification. The backup and checksum are retained under the root-only operator cutover directory.

The controller runs as the dedicated account in the transient `hotel-ai-speech-pilot.service` on loopback, with restart on failure. A host reboot removes this unit and leaves the routed workers stopped. Check journal and route state before starting the referenced primaries and restoring the controller listener. Keep guest traffic paused until bilingual inference and admin status pass. Automatic reboot recovery and live staff switching remain future work.
